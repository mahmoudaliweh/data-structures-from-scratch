# Segment TreeThe segment tree is a data structure used for storing information about intervals or segments of an array of elements.# Why Segment Tree?It allows efficient range queries over array intervals as well as updates.Types of operations:* Finding Range Sum Queries* Searching index with given prefix sum* Finding Range Maximum/Minimum* Counting frequency of Range Maximum/Minimum* Finding Range GCD/LCM* Finding Range AND/OR/XOR* Finding number of zeros in the given range or finding index of Kth zero* Updating a RangeYou could do these operations in O(log n) worst-case time.You could use a prefix sum array to answer range queries in O(1) but updates will take O(n), similarly you could use an array to update in O(1) but answering range queries will take O(n).# Structure of Segment TreeThe segment tree is generally represented using an array where the first value stores the value for the total array range and the child of the node at the ith index are at (2\*i + 1) and (2\*i + 2). Just like how you would represent a heap since it's a complete binary tree.# Applications* Database indexing (range aggregations)* Time-series analytics* Financial systems (range calculations)* Graphics engines (interval updates)# Time Complexity|Build|O(n)||-|-||Range Query|O(log n)||Range Update (with lazy propagation)|O(log n)|
